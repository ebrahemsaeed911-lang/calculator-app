# 🧮 Calculator

A responsive calculator built with **HTML, CSS, and Vanilla JavaScript**. This project is part of my journey to improve my JavaScript skills through hands-on practice and interactive web development.

## ✨ Features

- ➕ Basic arithmetic operations: addition, subtraction, multiplication, and division.
- ⌨️ Keyboard support for numbers and operations.
- 🔊 Button sound effects for mouse and keyboard interactions.
- 🎯 Keyboard button highlighting for visual feedback.
- 🎨 Theme toggle for switching the calculator's appearance.
- ⌫ Delete the last digit.
- 🔄 Reset the calculator.
- 🔢 Decimal number support.
- 📱 Responsive user interface.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🚀 Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/ebrahemsaeed911-lang/calculate.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build tools are required.

## ⌨️ Keyboard Shortcuts

| Key         | Action                |
| ----------- | --------------------- |
| `0–9`       | Enter numbers         |
| `.`         | Enter a decimal point |
| `+`         | Addition              |
| `-`         | Subtraction           |
| `*`         | Multiplication        |
| `/`         | Division              |
| `Backspace` | Delete the last digit |
| `Enter`     | Calculate the result  |
| `c`         | Reset the calculator  |
